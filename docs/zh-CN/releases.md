# 版本说明

[English](../en/releases.md) · [项目说明](README.md)

## 4.0.0

- 使用 `calendar.event.*` 和 `calendar.task.*` 替换旧的混合写入能力，分别定义资源请求结构和通知；统一读取使用 `calendar.entry.list/get`，移动快照刷新使用 `calendar.mobile-page.refresh`，不保留旧名称别名。详见[能力迁移说明](calendar-capabilities.md)。
- 新增重复日程：每天、周一至周五、自选星期、每周／每两周、每月同日／第几个星期几／最后一天、每年、自定义间隔及日期／次数结束条件。
- 新增周一至周日的周视图，支持重叠日程分列、每日待办、点击时段新建、跨月跨年导航与窄屏滚动，保留月视图和选中日期操作。详见[日历视图](calendar-views.md)。
- 新增增量迁移 `003_event_recurrence.sql`，保留已有 ID 和内容，已有条目默认为不重复。

### 兼容与升级

依赖已发布的 `Quantum.Plugin.Abstraction` **0.3.0-rc.3**，发布时使用 `--sdk-version-support ">=0.3.0-rc.2 <0.4.0"`。兼容范围包含 rc.2、不包含 0.4.0，构建依赖仍精确固定在 rc.3；该范围表示宿主 SDK，而不是桌面应用版本。使用已验证且支持此选项的 CLI（0.2.0 或更高版本）；CLI 0.1.1 不支持 SDK 兼容选项。发布与检查时一致的不可变安装包，不重新打包或覆盖已存在版本。

Calendar 4.0.0 与 Ledger 0.7.0 需同步升级；其他消费方须先迁移再使用日历联动。Xzzd 日历同步需要另行适配，不包含在本次发布内。工作日为周一至周五，不作节假日调整；编辑和删除重复日程作用于整个系列，暂不支持单次例外。

升级前保留应用数据的常规备份。如联动异常需要回退，应同时恢复 Calendar 3.0.0、Ledger 0.6.0 以及匹配的消费方版本。保留迁移 003 的新增列，不删除重复日程记录或修改已发布迁移来回退应用；旧日历版本不能展开新建的重复系列。记账关联继续使用系列 ID。

本次不改变身份认证或权限机制。验证覆盖生成客户端、重复规则边界、真实 SQLite 迁移、资源归属、周视图交互与前端滚动，检查命令见[开发说明](contributing.md)。签名版本标签对应已验证的合并历史，发布说明关联 PR、源码提交、持续集成运行和安装包校验值。

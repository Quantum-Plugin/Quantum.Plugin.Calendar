# 术语表

[English](../en/glossary.md)

<a id="sdk"></a>

## SDK（软件开发工具包）

Quantum.Plugin.Abstraction 提供的已发布开发抽象。

<a id="rpc"></a>

## RPC（远程过程调用）

通过生成的客户端和服务端处理的命名请求。

<a id="nof"></a>

## NOF 应用框架

提供处理器生成、依赖注入、映射和持久化的框架。

<a id="cli"></a>

## CLI（命令行界面）

通过命令操作的程序；Codex 需要单独安装并登录。

<a id="ci"></a>

## CI（持续集成）

自动执行构建、格式、测试和打包检查。

<a id="clr"></a>

## CLR（公共语言运行时）

.NET 运行时；程序集与命名空间名称属于兼容性契约。

<a id="ui"></a>

## UI（用户界面）

Blazor 页面、后台代码、样式和本地化资源。

<a id="css"></a>

## CSS（层叠样式表）

样式表，包括生成的组件作用域合并样式。

<a id="migration"></a>

## 迁移

宿主按顺序执行的数据库结构变更，用于保留既有数据并升级结构。

<a id="extension-point"></a>

## 扩展点

由宿主标注贡献方身份、按版本区分的可选插件数据通道。拥有者定义数据契约，其他插件注册、更新或撤回贡献，无需共享可执行的业务对象。

<a id="json"></a>

## JSON（JavaScript 对象表示法）

表示对象、数组、字符串、数字、布尔值和 null 的文本数据格式。JSON 结构定义描述允许的数据形状，日历还会校验日期关系及领域约束。

<a id="occurrence"></a>

## 日程实例

存储的日程序列中的一次日程。原定日期来自重复规则，实际日期来自明确选择的调休规则。系列标识与原定日期的组合可以区分被移动到同一个实际日期的不同实例。
